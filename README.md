# Image Gallery 🖼️

## About the Project
This is a responsive Image Gallery website built using HTML, CSS, and JavaScript.

## Features
- View beautiful images.
- Filter images by Nature and City.
- Previous and Next image navigation.
- Full-screen image preview.
- Responsive design for mobile and desktop.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download the project.
2. Open Image_Gallary.html in your browser.
3. Enjoy exploring the image gallery!
